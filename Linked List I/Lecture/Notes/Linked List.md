# Linked List

- It is a type of dynamic array that is alternative to `ArrayList`

- It connects items logically, instead of storing them in a continuous block of
memory

- That is, each item contains the address of the next item in line

$$
40 \rightarrow 50 \rightarrow 60 \rightarrow 70 \rightarrow 80 \rightarrow 90
$$

- This bypasses the need to expand the list every time it reaches full capacity
