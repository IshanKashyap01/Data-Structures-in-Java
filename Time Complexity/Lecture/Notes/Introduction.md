# Complexity Analysis

- It allows us to compare algorithms *quantitatively*, such that we can know
how fast/slow an algorithm is compared to another

- We analyse the *time* taken and the *space* consumed by an algorithm based on
the *size of input* provided

- Such analysis is called **time complexity** and **space complexity**
respectively

- There are too many variables involved in figuring out the actual time it may
take an algorithm on a given system

  - Such as number and speed of processors, memory, test cases used, etc.

- This makes practical analysis too complicated and time consuming

- Therefore, we turn to theoretical analysis instead
