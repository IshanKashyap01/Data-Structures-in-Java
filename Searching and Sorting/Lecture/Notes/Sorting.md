# Sorting

- **Sorting** refers to arranging elements in a collection into a specified
order (usually in ascending order)

- Following are a few of many sorting algorithms:

  - [Bubble sort](Bubble%20Sort.md)

  - [Selection sort](Selection%20Sort.md)

  - Insertion sort

  - Merge sort

  - Quick sort

  - Heap sort

  - Radix sort
